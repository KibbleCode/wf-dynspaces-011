# wf-dynspaces | Wayfire 0.11 Fork

An unofficial fork of **wf-dynspaces**, adapted for newer versions of Wayfire.

This fork was created by me with the help of AI-assisted coding (also known as *vibe coding*). The goal is to bring dynamic workspace functionality to Wayfire 0.11 while keeping the original project's idea alive.

## About This Fork

The original project is developed by **Val Packett** and is now hosted on Codeberg.

**Original project:** [wf-dynspaces on Codeberg](https://codeberg.org/valpackett/wf-dynspaces)

Since I use GitHub and don't have a Codeberg account, I've decided to share my modified version here.

This is an independent, community-made fork and is not an official release from the original developer.

### Compatibility

- Designed for Wayfire 0.11
- Tested on Artix Linux with Wayfire 0.11.0
- Compatibility with other Wayfire versions is not guaranteed
